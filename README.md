## Running Locally

Clone the repository:

```bash
git clone https://github.com/Rickson0628/Portfolio.git
```

Navigate into the project:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Available Scripts

```bash
npm run dev
```

Runs the application in development mode.

```bash
npm run build
```

Creates a production build.

